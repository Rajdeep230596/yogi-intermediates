# Yogi Intermediates

Redesign of [yogiintermediates.com](https://yogiintermediates.com/) — a motion-led marketing site for India’s bromine-derivatives manufacturer.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Framer Motion
- React Router
